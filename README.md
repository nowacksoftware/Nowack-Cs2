<a name="english"></a>
## 🇬🇧 English

External cheat template for Windows games.

### 🚀 Features
* **External:** Runs outside the game process.
* **Menu:** Press `Insert` in-game to toggle menu.

### ⚙️ Usage
1. Open the game.
2. Run program as Administrator.
3. Press `Insert` to open menu.
